# Changelog

## [0.1.0] - 2026-11-26
### Added
- Primera implementación navegable de Danubio Geoscientia.
- Arquitectura modular con HTML, CSS, JavaScript y datos JSON.
- Bilingüe español-inglés.
- Navegación adaptable y menú móvil.
- Nueve servicios especializados con detalles desplegables y cotización por selección.
- Flujo interactivo de gestión integral y consideraciones NI 43-101.
- Sección de tecnología, equipo modular y contacto.
- Generación de solicitud mediante `mailto` sin envío simulado.
- Archivos base para GitHub Pages y documentación de actualización.
